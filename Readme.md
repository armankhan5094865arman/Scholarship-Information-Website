# Scholarship Information Website

A frontend website created to practice and demonstrate my **HTML and CSS skills**. The website provides a simple interface for viewing university and scholarship-related information and includes multiple connected pages.

## 📌 About the Project

I created this project while learning **HTML and CSS**. My goal was to take the concepts I learned and use them to build a complete multi-page website instead of only practicing individual examples.

The website includes separate pages for **Home, About, Contact, and Scholarships**, with navigation links connecting the pages.

This project is mainly a **frontend learning project**. It does not currently have a backend or database.

## ✨ Features

* Multi-page website
* Home page
* About page
* Contact page
* Scholarships page
* Navigation between different pages
* University and scholarship information sections
* Eligibility criteria section
* Subjects and fee information tables
* University images
* Country selection dropdown
* Application procedure section
* Styled buttons and page layouts
* Responsive-style layout practice using HTML and CSS concepts

## 🛠️ Technologies Used

* **HTML5** — for creating the structure and pages
* **CSS3** — for styling, layouts, positioning, tables, navigation, and other visual elements

## 🚧 Current Limitations

This is currently a **frontend-only project**.

The three action buttons at the bottom of some pages are not functional yet because the website does not have a backend or database.

The scholarship information shown in the project is used for **learning and demonstration purposes** and should not be treated as an official source for current scholarship requirements, fees, or deadlines.
